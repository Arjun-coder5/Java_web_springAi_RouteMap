# **Why** :  
-         Servlets: Used by web servers (like Tomcat) to handle HTTP requests. Learn them because Spring Boot is built on the Servlet API, so they help you understand request handling, sessions, filters, and debugging.

-         JSP: Used to create dynamic HTML pages in legacy Java web applications. Learn only the basics, since modern applications use React/Angular + Spring Boot REST APIs instead of JSP.
